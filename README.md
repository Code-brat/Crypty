# Crypty

This repository contains a project that securely stores and retrieves data from a file especially passwords. Using the Caesar cipher encryption algorithm, the input text can be secure encrypted inside a file. This little single-files project will be turned into a full stack web application with libraries and frameworks such as ReactJS(frontend), Java Spring-Boot(Backend API) and SQL(Database).

## How it actually encrypts the data?

Let's say for example if we enter "abcdef" as the input, then it will be encrypted as "fghijk" when the key is 5. Which means each character in the word shift 5 times to the right. So, that's how it works. It's the same for decrypting, the encrypted data will be shift back towards the left 5 times to get the original data.
